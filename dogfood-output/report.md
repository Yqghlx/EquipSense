## 已发现并修复的问题

### Issue #1：网关设备配置页面没有可达的产品入口

| 字段 | 内容 |
|------|------|
| **严重级别** | 🟠 高 |
| **类别** | 功能 / UX |
| **位置** | `/gateways`、新增 `/gateway/devices` |
| **状态** | ✅ 已修复并回归通过 |

**问题描述：** 现有网关设备配置页面未注册路由，网关状态页也缺少进入设备配置和新建设备的明确入口。

**复现步骤：**
1. 登录后打开网关状态页。
2. 尝试进入网关设备配置。
3. 继续完成新建设备流程。

**期望行为：** 用户可以从网关状态页进入设备配置，也可以直接开始新建设备。

**实际行为（修复前）：** 页面路由与导航缺失，用户无法稳定到达现有配置能力。

**修复：** 注册 `/gateway/devices` 路由，增加侧边栏与网关状态页入口，并补充中英文 i18n 文案。

**证据：** 设备接入向导定向 Production smoke 19/19 通过。

### Issue #2：设备接入向导使用了分页语义文案

| 字段 | 内容 |
|------|------|
| **严重级别** | 🟡 中 |
| **类别** | UX / 内容 |
| **位置** | `/device-setup` |
| **状态** | ✅ 已修复并回归通过 |

**问题描述：** 四步设备接入向导的底部按钮复用了“上一页/下一页”文案，用户容易误解为列表分页，而不是向导步骤切换。

**期望行为：** 使用“上一步/下一步”，并在每一步保留配置内容。

**实际行为（修复前）：** 文案与向导交互语义不一致，旧 E2E 也因此依赖过时的文本假设。

**修复：** 新增 `gatewayWizard.previous` 和 `gatewayWizard.next` 中英文键，向导改用准确文案，并重写向导测试覆盖当前四步流程。

**证据：** 设备接入向导定向 Production smoke 19/19 通过；全量 E2E 无失败。

### Issue #3：关键 E2E 用例存在假绿或过时断言

| 字段 | 内容 |
|------|------|
| **严重级别** | 🟠 高 |

| **位置** | 告警详情、知识库候选规则、工单创建、设备接入向导 |
| **状态** | ✅ 已修复并回归通过 |

**问题描述：** 部分旧用例使用软断言或检查已不存在的 UI 结构，测试即使没有验证到关键结果也可能显示通过。

**修复：**

- 告警详情改为硬断言真实 Sheet 面板可见。
- 知识库改为硬断言候选规则卡片及内容可见。
- 工单创建硬断言弹窗关闭并断言新工单标题出现。
- 设备接入向导按当前四步流程重写，覆盖连接测试、校验、返回保留、多个数据点及创建 API 清理。

**证据：**

- 全量 Production E2E：433 总计，431 通过，2 条件跳过，0 失败。
