# 生产凭据独立性与运行时门禁实施计划

## 目标

阻止生产部署在数据库、缓存、消息队列、监控服务、MQTT、安全密钥和高权限种子账户之间复用同一凭据；同时在部署前确认挂载的 TLS/MQTT 证书真实可用，并让 E2E 验收凭据可以安全注入。

## 设计原则

- 复用现有 `docker/validate-env.sh`，不引入第二套环境变量解析器。
- 只比较环境文件中的值，错误信息只报告变量名和修复建议，绝不输出凭据或密钥内容。
- 生产环境由应用启动校验和部署前校验双重拒绝；开发环境保持原有演示数据兼容性。
- 所有新增注释、日志和文档使用简体中文。
