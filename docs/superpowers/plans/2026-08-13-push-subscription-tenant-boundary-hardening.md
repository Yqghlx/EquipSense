# 推送订阅租户边界加固实施计划

## 目标

修复 Web Push 订阅注册/注销绕过全局租户过滤器后缺少租户归属校验的问题，避免跨租户删除订阅或接管全局唯一的浏览器 endpoint。

## 实施步骤

1. 添加跨租户注销红测，验证旧实现会删除其他租户订阅。
2. 添加跨租户 endpoint 注册红测，验证旧实现会改写其他租户订阅的租户和用户归属。
3. 注销查询增加当前租户条件；注册检测到 endpoint 已属于其他租户时返回业务冲突，同租户重复注册继续更新。
4. 运行推送相关测试、全量单元测试、Release 构建并进行独立审查后提交。

## 验收标准

- 当前租户不能注销其他租户的订阅。
- 当前租户不能接管其他租户已登记的 endpoint。
- 同租户重复注册仍更新订阅密钥和用户归属。
- 全量单元测试、Release 构建和独立审查通过。

## 验证记录

- 跨租户注销/注册红测覆盖旧实现的删除和接管副作用；修复后均保持原租户记录不变。
- 推送订阅测试：10/10 通过。
- 全量单元测试：1569/1569 通过。
- Release 构建：0 警告、0 错误。
