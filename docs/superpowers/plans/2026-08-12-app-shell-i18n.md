# 应用壳层反馈与无障碍文案国际化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将全局加载、错误、连接、离线、安装和导航文案统一接入中英文资源，提升故障场景可理解性和键盘/读屏可用性。

**架构：** 将 App 内部反馈状态抽为 `AppFeedback.tsx` 函数组件；class 错误边界使用翻译 HOC 注入 `t`。现有状态管理、路由、认证、SignalR 和 PWA hooks 不变，只替换展示层文案与可访问名称。

**技术栈：** React 19、TypeScript strict、react-i18next、Vitest、Testing Library、React Router。

## 全局约束

- 所有新增注释、文档和用户可见日志使用简体中文。
- 中英文 JSON 资源键集合必须完全一致。
- 不改变认证、路由、SignalR 重连或 PWA 安装行为。
- 必须先看到英文回归测试因硬编码中文失败，再写生产实现。
- TypeScript、Lint、i18n、生产构建和现有前端测试必须通过。
