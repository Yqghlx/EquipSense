# 知识规则导出租户边界加固实施计划

## 目标

让知识规则 JSON/CSV 导出始终使用方法参数中的目标租户过滤，避免服务被后台任务或异常上下文复用时仅依赖全局查询过滤器而返回错误租户数据。

## 实施步骤

1. 添加 JSON/CSV 传入其他租户 ID 时不得导出当前租户规则的红测。
2. 在两种导出查询中显式增加 TenantId 条件，并保持设备类型过滤与输出格式不变。
3. 运行知识导出专项测试、全量回归和独立审查后提交。

## 验收标准

- JSON 和 CSV 导出均按显式 tenantId 过滤。
- 传入错误租户 ID 时不返回当前租户规则。
- 现有格式、设备类型过滤和行业预置导入行为不受影响。

## 验证记录

- 旧实现红测：JSON/CSV 共 2 项失败，确认测试能捕获参数未生效。
- 知识导入导出测试：19/19 通过。
