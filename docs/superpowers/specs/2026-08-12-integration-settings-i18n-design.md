# 外部集成配置可靠性与国际化设计

## 目标

让钉钉、飞书、Webhook 和 EAM 配置面板在英文界面下完整可用，并确保页面加载已有配置后，禁用或保存操作不会因为表单未回填而覆盖线上配置。

## 范围

- 四种集成的标签页、状态徽章、连接测试和启停按钮。
- Webhook、签名、API、审批定义、Body 模板和 EAM 认证字段的中英文文案。
- 从后端返回的已有集成配置回填到对应表单状态。
- 保存/禁用时沿用安全回填的非敏感配置；敏感字段保持空白，由后端按脱敏摘要和合并规则保留服务端真实值。
- 集成测试成功耗时和失败提示的英文表达。

## 设计决策

1. 使用 `useEffect` 在集成数据加载完成后按字段白名单回填表单，避免把后端状态对象直接作为可编辑状态，防止无关字段或 `unknown` 值进入请求。
2. 对可选字符串统一使用类型守卫；后端缺少字段时使用当前编辑值，避免异步查询返回部分配置时清空用户刚输入的内容。
3. 所有用户可见文案归入 `settings.integrations.*`，复用 `common.*`、`auth.*` 的通用操作和认证字段；变量模板与 JSON 示例保留为技术内容，不参与翻译。
4. 测试连接、启停和保存行为保持现有 API 类型与请求结构不变，只补充回填和展示层行为。

## 验证标准

- 改造前英文回归测试因硬编码中文和配置未回填而失败。
- 改造后四类集成的英文界面、已有配置回填和禁用请求保留配置的测试通过。
- 前端全量测试、TypeScript、Lint、i18n 键覆盖、生产构建和差异检查全部通过。
