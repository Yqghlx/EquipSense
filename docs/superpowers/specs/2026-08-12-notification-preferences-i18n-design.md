# 通知偏好设置国际化设计

## 目标

将通知偏好矩阵和浏览器推送订阅状态统一接入中英文资源，让用户准确理解告警、工单、系统通知与实时/浏览器/邮件渠道的关系。

## 范围

- 通知偏好卡片标题、说明、加载状态和矩阵表头。
- 三类通知类型及其说明、三类通知渠道及其说明。
- 浏览器推送能力、订阅状态和浏览器权限提示。
- 保持开关状态、禁用条件、订阅/取消订阅和更新 API 行为不变。

## 设计决策

1. 配置数组只保存稳定业务键和翻译键，组件渲染时调用 `t`，避免模块级常量固定为某一种语言。
2. 推送能力和权限提示使用独立资源键，明确区分“不支持浏览器”“尚未订阅”和“权限被拒绝”三种可操作状态。
3. 本次只替换展示层文案，不改变偏好矩阵的更新载荷和浏览器 Push 回调。

## 验证标准

- 改造前英文回归测试因硬编码中文失败。
- 改造后覆盖加载、偏好矩阵、Push 状态和权限提示的英文测试通过。
- 前端全量测试、TypeScript、Lint、i18n 键覆盖、生产构建和差异检查全部通过。
