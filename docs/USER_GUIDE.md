# EquipSense 用户操作指南

## 系统概述

EquipSense 是工业设备智能监控与预测维护平台。核心能力：**实时监控 → 智能告警 → AI 根因分析 → 自动工单闭环**。

## 登录

访问系统首页，输入用户名和密码登录。默认管理员账号：`admin / Admin@123`。

## 功能模块

### 1. 仪表盘

系统首页，展示全局统计概览：
- **租户统计**：总租户数、活跃租户、试用租户
- **设备统计**：总设备数、在线/活跃设备数
- **工单统计**：待处理工单数
- **设备可用率**：百分比指标
- **最近告警**：最近触发的告警列表

### 2. 设备管理

#### 设备列表
- 查看所有设备，支持搜索和状态过滤
- 点击"新建"按钮添加设备
- 设备信息包括：编码、名称、类型、状态、型号

#### 设备详情
- 点击设备行进入详情页
- 查看设备基本信息、实时遥测数据、历史趋势图
- 查看设备关联的告警和工单

#### 设备类型
系统预置 6 种设备类型：pump（泵）、motor（电机）、valve（阀门）、sensor（传感器）、plc（PLC）、other（其他）。

### 3. 告警中心

#### 告警列表
- 按状态过滤：全部、活跃、已确认、已解决
- 按级别过滤：紧急、高、普通、低
- 点击"确认"按钮确认活跃告警

#### 告警规则
- 配置阈值告警规则
- 设定指标阈值和触发条件
- 规则启用/禁用控制

### 4. 工单管理

#### 创建工单
1. 点击"新建"按钮
2. 填写标题、选择类型（纠正性/预防性/预测性/巡检）
3. 选择优先级（紧急/高/普通/低）
4. 关联设备
5. 填写问题描述后保存

#### 工单详情
- 查看工单完整信息、审批进度
- 执行状态流转操作
- 查看关联的 AI 分析结果

### 5. AI 分析

- 查看系统自动生成的根因分析报告
- 分析级别：L1（LLM）、L2（规则）、L3（统计）、L4（ML 预测）
- 分析包含：故障原因、置信度、建议措施

### 6. 知识库

三个 Tab 页签：
- **诊断规则**：已验证的知识规则，由专家审核后入库
- **待审核**：AI 自动生成的候选规则，等待专家验证
- **故障案例**：历史故障记录和处理方案

支持规则搜索、导入/导出功能。

### 7. 派工看板

- 查看待派工的工单
- 智能推荐匹配的技术人员
- 按技能和位置派工

### 8. 系统设置

#### 通知订阅
- 订阅浏览器推送通知
- 按告警级别和设备范围配置通知偏好

#### 审批链配置
- 配置工单审批流程模板
- 设定审批角色和顺序

#### 外部集成
- 钉钉集成：配置 Webhook URL 和签名密钥
- 飞书集成：支持简化模式和应用模式
- Webhook 集成：通用 HTTP 推送
- EAM 集成：对接 Maximo/SAP PM

## 离线使用

系统支持 PWA 离线访问：
- 已浏览的页面在离线状态下仍可查看
- 离线时创建的操作自动存入队列
- 恢复网络后自动同步离线操作

## 常见问题

**Q: 忘记密码怎么办？**
A: 联系 SystemAdmin 重置密码。

**Q: 设备不显示实时数据？**
A: 检查边缘网关是否正常运行、MQTT 连接是否正常。

**Q: 告警未触发？**
A: 检查告警规则是否启用、阈值设置是否合理、设备是否有遥测数据上报。
