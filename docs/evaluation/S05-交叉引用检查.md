## 三、交叉引用执行方案

由于 19 份报告两两交叉引用的改动量很大，建议按以下方式批量处理：

1. **按模板统一加末尾"关联报告"导航段**
2. **模板格式**：
   ```
   ---
   ## 关联报告

   | 领域 | 报告 |
   |------|------|
   | 架构 | [02-后端架构分析](./02-后端架构分析.md) · [03-前端架构分析](./03-前端架构分析.md) |
   | 专题 | [09-数据库](./09-数据库与数据架构分析.md) · [10-API](./10-API面与接口契约分析.md) |
   | 总览 | [S01-全系统架构总览图](./S01-全系统架构总览图.md) |
   ```
3. **在 00-INDEX 已实现完整映射**，可作为"中央路由"
4. **S01/S02/S03 三份"导航型"报告已处理所有高层引用**

**建议**：11 份领域报告（02-12, 14）各加一个"关联报告"尾部段落，工作量约 30 分钟。可以直接批量处理。
