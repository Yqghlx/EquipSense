## 三、已知 CVE 与漏洞状态

### 3.1 NuGet 漏洞

`Directory.Build.props` 已启用 `TreatWarningsAsErrors=true`，仅保留与版本自动解析有关的 `NU1603`；`NU1901`/`NU1903` 不再抑制。CI 显式执行：

```bash
dotnet list EquipAI.sln package --vulnerable --include-transitive
```

2026-08-09 联网复核结果：全部源码与测试项目均未发现已知漏洞包。AutoMapper 保持在 15.1.3；不得为规避许可证降级，因为所有低于 15.1.1 的版本受高危递归拒绝服务漏洞影响。生产环境通过 `AutoMapper__LicenseKey` 注入供应商密钥，应用启动门禁和 `docker/validate-env.sh` 会拒绝缺失、占位或过短值。参考 [GHSA-rvv3-g6hj-g44x](https://github.com/advisories/GHSA-rvv3-g6hj-g44x)。

前端同时执行生产依赖精确例外审计和全量 `npm audit --audit-level=high`。审计脚本已验证 npm 返回的是完整漏洞报告；漏洞源网络/鉴权失败时会阻断流水线，不能再被误报成“零漏洞”。2026-08-09 联网复核为 `found 0 vulnerabilities`。

### 3.2 Trivy 镜像扫描

CI 对 main 镜像和版本发布镜像均使用 `exit-code: '1'` 扫描 `HIGH,CRITICAL`，发现漏洞即阻断；`ignore-unfixed: true` 保留为当前风险接受策略。
