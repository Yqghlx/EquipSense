## 三、已知 CVE 与漏洞状态

### 3.1 NuGet 漏洞

```xml
<!-- Directory.Build.props — 当前状态 -->
<NoWarn>NU1603;NU1901;NU1903</NoWarn>
```

| 抑制码 | 含义 | 影响 |
|--------|------|------|
| NU1603 | 版本自动解析 (依赖版本提升) | 低 — 仅警告 |
| NU1901 | NuGet 已知 CVE (中危) | **中** — 有已知漏洞未修复 |
| NU1903 | NuGet 已知 CVE (高危/严重) | **高** — 有已知严重漏洞未修复 |

⚠️ **风险**：当前所有 NuGet CVE 均在 CI 和生产中静默忽略。建议排查具体哪个包有 CVE 并升级。

### 3.2 Trivy 镜像扫描

```yaml
# CI 中已启用的扫描
exit-code: '0'    # 不阻断 (仅输出)
ignore-unfixed: true
severity: HIGH,CRITICAL
```

**建议**：逐步修复 HIGH/CRITICAL CVE 后将 `exit-code` 改为 `1` 阻断 CI。
