## 二、领域层 (Core)

### 2.1 实体关系图谱

```
Tenant → User (RBAC 五角色)
       → Device (JSONB 灵活字段, HealthScore, DeviceTypeTemplate)
            → MetricBaseline (动态基线 Z-Score)
            → DeviceTelemetry (TimescaleDB 超级表, 时序窄表)
       → AlertRule (阈值/组合/基线三类) → Alert (含聚合防风暴)
            → Analysis (AI 四级降级分析)
                 → WorkOrder (9 种状态) → WorkOrderLog
                      → KnowledgeRule / PendingRule (双表审核)
                      → FaultCase → FmeaEntry
```

## 三、应用层 (Application)

### 3.1 模块划分

| 模块 | 核心文件 | 职责 |
|------|---------|------|
| Alerts | AlertEvaluationService, AlertAggregator, Threshold/Baseline/CombinedEvaluator | 告警评估 + 防风暴 |
| Analysis | RootCauseAnalysisEngine, DataQualityService, DeviceHealthService, OeeService | 四级降级 AI 管线 |
| WorkOrders | WorkOrderService, SmartDispatchService, SlaManagementService | 工单全生命周期 |
| Knowledge | KnowledgeCaptureService, KnowledgeConflictService, RuleAccuracyTracker | 知识沉淀闭环 |
| Eventing | InMemoryEventBus (Channel<T>) | 事件驱动核心 |

### 3.2 InMemoryEventBus

```csharp
Channel<IIntegrationEvent> — 容量 1000, DropOldest
单消费者后台任务, 每事件独立 DI Scope
反射分发 HandleAsync 方法 (防 AmbiguousMatchException)
```

### 3.3 告警评估引擎

```
TelemetryReceivedEvent → TelemetryEventHandler → AlertEvaluationService
  1. 查询 MetricBaseline (IFQF)
  2. 查询匹配 AlertRule (TenantId + Metric + DeviceId + DeviceType)
  3. 遍历规则 → 匹配评估器 (Threshold/Baseline/Combined)
     ├── 触发 → AlertAggregator: 第1次创建/2-3次更新/>3静默
     └── 未触发 → TryAutoResolveAsync (Active→Resolved)
```

### 3.4 工单状态机

```
PendingDispatch → Assigned → InProgress → Completed → Accepted → Closed
       │                      │              │             │
       ├─ Cancelled ←─────────┤        ┌─────┘        (终态)
                                │       │
                           SubmittedFor  Rejected
                           Approval       │
                               │      (返工→InProgress)
                           Accepted
```

## 四、基础设施层 (Infrastructure)

### 4.1 全局多租户过滤器 (AppDbContext)

```csharp
// 动态表达式树，每查询时评估 ITenantContext.TenantId
// Tenant 表本身不受限
// 所有含 TenantId 属性的实体自动注入 WHERE tenant_id = @current
```

**重要约束**：后台 Service（无 HttpContext）必须 `IgnoreQueryFilters()` + 显式按事件 TenantId 限定。该模式在后端约 100 处使用。
