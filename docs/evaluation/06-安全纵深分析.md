# EquipSense 安全纵深专项分析报告

> 分析日期：2026-06-24 · 范围：22 个安全相关文件 · 等保 2.0 三级对照

## 一、七层纵深防御

```
Layer 1: 物理/网络     — Nginx TLS 1.2+ · mTLS (边缘网关) · Docker 非 root
Layer 2: WAF+输入过滤   — WafMiddleware · InputSanitizationMiddleware
Layer 3: 速率限制+配额  — 1000/租户/min + 60/IP/min + 10/login/min
Layer 4: 认证          — JWT + HttpOnly Cookie + Refresh Token + MFA/TOTP
Layer 5: 鉴权          — TenantResolution + PermissionMiddleware + RBAC 矩阵
Layer 6: 数据隔离       — EF Core 全局租户过滤器 + SignalR Group 隔离
Layer 7: 审计追溯       — AuditActionFilter · 7 类写操作审计 · 语义化 resourceId
```

## 二、认证体系

### 2.1 双令牌架构

| 令牌 | 存储 | 有效期 | 可吊销 |
|------|------|--------|--------|
| Access Token (JWT) | HttpOnly Cookie | 15min (可配置, 钳制 10min-24h) | 否 (无状态) |
| Refresh Token | Redis (正向+反向索引) | 7 天 | 是 |

### 2.2 Token 三源优先级

```
1. QueryString access_token (SignalR WebSocket)
2. HttpOnly Cookie (浏览器, 防 XSS)
3. Authorization Header (向后兼容)
```

### 2.3 登录安全

| 控制 | 参数 |
|------|------|
| 连续失败锁定 | 5 次 → 锁定 15 分钟 |
| 统一错误信息 | "用户名或密码错误" (防枚举) |
| 停用账户拒绝 | IsActive == false |
| 首次强制改密 | MustChangePassword == true |
| MFA/TOTP | 6 位, 30s 窗口, ±1 步偏移 (RFC 6238) |

### 2.4 Refresh Token 重放检测 (OAuth 2.0 BCP)

```csharp
// Redis 三态:
// Valid   → 当前有效
// Reused  → 已轮换的旧令牌 (墓碑) → 重放攻击 → 吊销整个会话
// Unknown → 不存在
```

## 四、WAF + 输入过滤

### WafMiddleware — 4 类攻击

| 类型 | 检测模式 |
|------|---------|
| SQL 注入 | UNION SELECT, OR 1=1, DROP TABLE |
| 路径遍历 | `../`, `..\\`, %2e%2e, /etc/passwd |
| 命令注入 | 管道符, 反引号, $(), curl/wget |
| XSS | script, 事件处理器, javascript: 协议 |

### InputSanitizationMiddleware — 40+ 事件处理器

覆盖 onclick/onload/onerror/onmouse*/onkey*/onchange/onsubmit 等

### CSP 策略

```http
default-src 'self'; script-src 'self' 'unsafe-eval'; style-src 'self' 'unsafe-inline';
img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' wss: https:;
object-src 'none'; frame-ancestors 'none'; base-uri 'self'; form-action 'self';
upgrade-insecure-requests
```

## 五、速率限制

| 层 | 分区 | 限制 |
|----|------|------|
| 已认证请求 | 按 tenant_id | 1000/min |
| 未认证请求 | 按 RemoteIp | 60/min |
| 登录端点 | 按 RemoteIp | 10/min (防暴力破解) |

## 六、审计追溯

全局 `AuditActionFilter` 拦截所有 POST/PUT/PATCH/DELETE，自动记录：
- 资源类型: Controller 名推断或 `[Audit]` 特性
- 资源 ID: 路由 id → 方法参数 *Id → 响应 DTO 反射 Id
- 描述: 含 HTTP 状态码区分成功/失败
