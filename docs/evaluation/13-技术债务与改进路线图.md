## 三、P1 — 短期内处理（1-2 周）

| # | 项 | 来源 | 影响 | 方案 |
|---|-----|------|------|------|
| 5 | **InMemoryEventBus 扩容** | 🏗 ⚡ | Channel 1000 满丢事件 | 扩容到 10000，并规划 RabbitMQ 架构 |
| 6 | **工单编码并发冲突** | 🏗 | 并发创建时可能产生重复编码 | 用 DB sequence 或 Redis INCR |
| 7 | **Trivy 改为阻断 CI** | 🔄 | 已知 CVE 不阻止部署 | 修复后 `exit-code: 1` |
| 8 | **K6 压测集成 CI** | 🔄 ⚡ | 无法检测性能退化 | CI 中添加 `k6 run` + 阈值 |
| 9 | **添加 CD 自动部署** | 🔄 | 镜 像推送后手动 deploy | SSH/ArgoCD deployment job |
| 10 | **语义版本号** | 🔄 | `:latest`+`:sha` 无法区分版本 | git tag 自动化 semver |
| 11 | **TelemetryService 同步阻塞修复** | 📐 ⚡ | `GetAwaiter.GetResult()` 阻塞线程 | 改为 `ValueTask` 异步 |
| 12 | **Jaeger/Tempo 容器** | 📊 | OTel 只能 Console 输出 | docker-compose 添加 `jaeger:16686` |
| 13 | **边缘网关 API 强制 HTTPS** | ⚙ 🔒 | AuthKey HTTP 明文传输 | GatewayOption 添加 `UseHttps` |
| 14 | **NuGet 漏洞不再静默** | 📦 | 删除 NU1901/NU1903 抑制 | 升级依赖后移除 NoWarn |
| 15 | **Prometheus 告警规则文件** | 📊 | 只有路由配置，无告警规则 | 创建 `rules.yml` 定义告警阈值 |
