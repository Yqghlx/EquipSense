## 一、汇总方法论

所有改进项按 Eisenhower 矩阵分类：

```
                   紧急                    不紧急
               ┌──────────────┬──────────────────┐
    重要       │  P0 (立即)    │  P1 (短期内 1-2周)│
               │  安全/数据风险  │  架构/功能缺口     │
               ├──────────────┼──────────────────┤
    不重要     │  P2 (中期 1月) │  P3 (长期 3月+)   │
               │  代码整洁/测试   │  可扩展性增强      │
               └──────────────┴──────────────────┘
```
