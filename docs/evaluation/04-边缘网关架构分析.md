# EquipSense 边缘网关架构专项分析报告

> 分析日期：2026-06-24 · 范围：src/EquipAI.EdgeGateway/ 全部 18 文件 · ~1,500 行

---

## 一、架构定位

独立的 .NET 8 控制台应用，部署在工厂现场边缘服务器上，职责链：

```
物理设备 (CNC/PLC/注塑机) → 边缘网关 (EquipAI.EdgeGateway) → MQTT → 后端平台
```

### 依赖

| 包 | 版本 | 用途 |
|---|------|------|
| FluentModbus | 5.3.2 | Modbus TCP/RTU |
| Microsoft.Data.Sqlite | 10.0.8 | 断网缓存 |
| MQTTnet | 4.3.7.1207 | MQTT 发布 |
| OPCFoundation.NetStandard.Opc.Ua.Client | 1.5.378.145 | OPC UA 客户端 |
| System.IO.Ports | 9.0 | Modbus RTU 串口 |

**零 ASP.NET Core 依赖**，轻量级，~15MB 镜像。

## 二、数据管线

```
DataCollector (BackgroundService, 每设备一个)
  → IProtocolAdapter.ReadAsync() → List<DataPoint>
  → DataNormalizer.Normalize() → NormalizedMessage (映射反转)
  → CloudUploader.UploadWithFallbackAsync()
      ├── MQTT 在线: 直接发布 + 回放积压数据
      └── 离线: → LocalBuffer (内存 10,000 环形队列)
                → 溢出 → SqliteBufferStore (7 天保留)
                → 恢复后自动回放 ReplayOfflineDataAsync()
```

### 2.1 核心循环 (DataCollector)

```
while (!stoppingToken)
  if (!adapter.IsConnected) → ConnectAsync
  await CollectOnceAsync()  → 读取 → 标准化 → 上传
  catch → DisposeAsync → 重建适配器 → 指数退避重连 (1s→2s→...→5min)
  await Task.Delay(PollIntervalMs)
```

### 2.2 标准化 (DataNormalizer)

```csharp
// 反转 DeviceConfig.DataPoints 映射
// key=指标名 (temperature), value=协议地址 (holding_register:100)
// NormalizedMessage: { device_id, timestamp, metrics:{...}, status, quality }
```

## 三、协议适配器 (3 种)

### 3.1 接口

```csharp
public interface IProtocolAdapter : IAsyncDisposable
{
    Task ConnectAsync(DeviceConfig config, CancellationToken);
    Task<List<DataPoint>> ReadAsync(string[] pointIds, CancellationToken);
    bool IsConnected { get; }
    string ProtocolType { get; }
}
```

### 3.2 OPC UA (OpcUaAdapter, ~290 行)

| 特性 | 说明 |
|------|------|
| SDK | OPC Foundation 1.5.378.145 |
| 安全模式 | None (开发) / Sign / SignAndEncrypt (生产) |
| 证书 | PFX 客户端证书 + 信任目录 + 过期检测 |
| 类型转换 | double/float/int/long/bool/decimal/short 等统一转 double |

### 3.3 Modbus TCP (ModbusTcpAdapter, ~180 行)

| 特性 | 说明 |
|------|------|
| SDK | FluentModbus 5.3.2 |
| 点位格式 | holding_register:100 / input_register:50 / coil:0 / discrete_input:1 |
| 连接格式 | IP:端口 (端口默认 502) |
| IPv6 | 支持 [::1]:502 格式 |

### 3.4 Modbus RTU (ModbusRtuAdapter, ~120 行)

| 特性 | 说明 |
|------|------|
| SDK | FluentModbus + System.IO.Ports |
| 连接格式 | 端口:波特率:数据位:校验:停止位:从站地址 |
| 例 | /dev/ttyUSB0:9600:8:N:1:1 |

## 四、断网保护

### 4.1 两级缓冲

```
DataCollector → LocalBuffer (ConcurrentQueue, 10,000 条)
                  → 溢出 → SqliteBufferStore (7 天保留)
网络恢复 → CloudUploader.ReplayOfflineDataAsync() → MQTT 回放
```

### 4.2 SQLite 表结构

```sql
CREATE TABLE buffer_messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    topic TEXT NOT NULL,
    payload BLOB NOT NULL,
    created_at TEXT DEFAULT (datetime('now')),
    is_sent INTEGER DEFAULT 0
);
```

## 六、配置与安全

### 6.1 配置来源

```
优先级 1: 后端 API GET /api/v1/gateway/config?gatewayId=&tenantId=
优先级 2: 本地 appsettings.json (后端不可用时 fallback)
```

### 6.2 安全控制

| 控制 | 实现 |
|------|------|
| 网关认证 | X-Gateway-Auth-Key Header |
| 配置隔离 | (tenantId, gatewayId) 双重限定 |
| OPC UA 签名 | Sign/SignAndEncrypt 可选 |
| 非 root 运行 | USER equipai |
| AuthKey 校验 | 纯 ASCII 检测 (防中文占位符) |
