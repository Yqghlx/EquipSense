## 二、状态管理 — 三权分立

```
TanStack Query Cache          ← 服务端数据 (自动失效/重新获取)
  30+ hooks: devices · alerts · work-orders · knowledge · ...

Zustand Stores (3)            ← 全局 UI 状态 (跨组件同步)
  · authStore: user, isAuthenticated (sessionStorage)
  · notificationStore: push, markRead (内存队列, 最多 50 条)
  · realtimeStore: connection status (disconnected→reconnecting→connected)

Component State (useState)    ← 局部 UI 状态
  · filter values, pagination, drawer open/close
```

### authStore 关键设计

```typescript
// 模块加载时同步恢复，不在 useEffect 中调用
// 避免页面刷新后：AuthGuard 读 isAuthenticated=false → 跳 /login
// 然后 useAuth 恢复后 → 跳回 /dashboard (flash of wrong page)
export const useAuthStore = create<AuthState>((set) => ({
  ...loadFromStorageSync(),  // 同步执行！
}));
```
