# EquipSense 项目评估报告索引

> 评估日期：2026-08-13（本轮实测） · 代码基线：~11 万行（源码+测试） · 单开发者
> 项目版本：v1.2.0 · 文档版本：v4.12（14 份专项报告 + 13 份补充图册，持续按实测结果校正）

> **最新候选状态（2026-08-13）**：租户配额在真实 PostgreSQL 中改为独立 `SELECT ... FOR UPDATE` 后再以新语句快照计数/更新；并发导入在去重前取得租户锁，消除稳定复现的 7×500；告警事件按 `EventId` 幂等，持久化失败交由 Inbox 重试，邮件发送前续租且租约至少 30 秒。审批链的通过、驳回、重提清理、详情和待审批列表现在均显式带租户条件，审批通过/驳回在服务层强制校验当前角色和指定审批人，待审批查询对角色不匹配、指定人不匹配或角色缺失 fail-closed；新增跨租户、角色越权和指定审批人越权负向回归，并验证角色/指定审批人越权返回 403、跨租户资源不可见返回 404；另新增 7 个真实 HTTP 集成回归，覆盖 JWT、租户解析、权限中间件、控制器到服务层的审批成功、越权无副作用和待办过滤链路。运营 CSV 报表现在对设备编码、设备名称和指标名执行 RFC 4180 转义，并对公式前缀做 Excel 文本保护，新增危险文本回归。FMEA 现在接入 L2 规则诊断，并通过按设备类型选择知识规则的只读摘要接口接入表单：命中规则后按当前租户优先、RPN 降序最多带回 3 条启用关联条目，输出故障模式、原因、影响、检测和维护建议；新增规则优先级、租户隔离、禁用条目、诊断编排和选择器清除回归，并为关联查询补充索引/迁移。CI 的 main/latest 与版本发布等待对应质量门禁，三张镜像全部通过固定 SHA 的 Trivy Action 后直接推送同一批已扫描本地标签，Release 创建使用独立最小权限 job，38 次 Action 调用全部固定完整 SHA，workflow + event + ref 并发组阻止旧 main run 回写 `latest`，服务就绪等待超时会失败关闭。生产运行时清单、Compose 文件、环境文件和校验器入口现在统一拒绝符号链接，避免直接挂载/执行路径越界；标准 Compose 默认注入 Jaeger OTLP，后端 Production 启动门禁拒绝空端点、非法地址和内嵌凭据，避免回退 Console exporter 或泄露 URL 敏感信息；Production smoke 显式启动 Jaeger 初始化/查询服务，并通过 `/api/services` 与 `/api/traces` 验证真实 trace 接收；后端单元 1692/1692、默认集成 193 总数（187 通过、6 跳过、0 失败）、前端 Vitest 494/494、Release 构建 0 警告/0 错误；当前 Production 三镜像 435 条 E2E 为 434 通过、1 个架构性条件跳过、0 失败。2026-08-13 联网复核中，NuGet 8 个项目与 npm 完整锁文件均为 0 个已知漏洞；当前 SDK 8.0.419 只能使用 `EquipAI.sln`，失效的 `.slnx` 遗留入口已移除并由契约测试防回归。CI 供应链三项代码缺陷、同引用并发竞态、解决方案入口、运行时文件边界、Production OTLP 策略、审批租户边界、审批角色越权、指定审批人约束和 403 错误映射问题已通过契约/单元/集成测试收口，首次真实 GitHub tag/main run、正式 OTLP 端点存储验收仍待完成；真实环境仍有 27 项发布门禁，SMTP 到达率、现场协议与容量基线仍待完成。

> **边缘网关并发增量（2026-08-13）**：`LocalBuffer` 现在以短锁原子完成容量驱逐/入队，锁外执行 SQLite 持久化；共享 `SqliteBufferStore` 的初始化、写入、回放、清理和释放统一经过异步闸门，出队同步维护队列深度指标。新增非法容量、并发入队、出队指标和共享 SQLite 并发写入回归；后端全量单元测试现为 1692/1692，边缘网关聚焦 33/33 通过。真实断网长时间积压、磁盘耗尽、MQTT 恢复、现场 PLC/OPC UA/Modbus 联调和容量基线仍需部署侧验收。

> **CloudUploader 回放并发增量（2026-08-13）**：单例 `CloudUploader` 现在以可取消的异步闸门保护离线积压读取、MQTT 发布、发送标记和清理的完整批次，避免多设备采集器在网络恢复时重复发布；发布失败保留积压记录，等待闸门支持停机取消。新增并发重复发布、等待取消、失败保留/重试回归，聚焦 13/13 通过；保护仅覆盖单进程实例，跨进程共享 SQLite 仍需消息租约设计。

> **网关代理取消传播增量（2026-08-13）**：配置连接测试、全局网关状态和指定网关状态代理现在只把普通网络异常转换为回退/离线结果，调用方取消和宿主停机继续传播；新增 3 条控制器/服务层回归，后端全量单元测试现为 1692/1692。

> **边缘网关健康端点取消传播增量（2026-08-13）**：协议连接测试在宿主停机时继续传播取消，不再转换为普通连接失败响应；请求处理器也不再把停机取消记录成错误。新增真实 `HttpListener` 停机回归，健康端点聚焦 7/7 通过。
