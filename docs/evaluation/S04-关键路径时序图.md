## 二、401 刷新令牌典型时序

```
┌─────────┐        ┌─────────┐        ┌─────────┐        ┌─────────┐
│ 前端页面  │        │ api.ts  │        │ Backend │        │ Redis   │
│ (Hook)   │        │ Axios   │        │ API     │        │         │
└────┬────┘        └────┬────┘        └────┬────┘        └────┬────┘
     │                  │                  │                  │
     │ 1. API 请求       │                  │                  │
     │─────────────────>│                  │                  │
     │                  │ 2. HTTP GET      │                  │
     │                  │ (Cookie auto)    │                  │
     │                  │─────────────────>│                  │
     │                  │                  │ 3. JWT 已过期    │
     │                  │                  │ 返回 401         │
     │                  │<─────────────────│                  │
     │                  │                  │                  │
     │                  │ 4. 检查 isRefreshing               │
     │                  │第一次 → 设为 true                  │
     │                  │5. POST /auth/refresh              │
     │                  │  (Cookie auto)                     │
     │                  │───────────────────────────────────>│
     │                  │                  │                 │
     │                  │                  │ 6. 验证正向+反向 │
     │                  │                  │   索引一致性     │

     │                  │<───────────────────────────────────│
     │                  │                  │                 │
     │                  │ 7. 重放原始请求   │                 │
     │                  │  (Cookie 已更新)   │                 │

     │                  │ 8. 通知排队请求   │                 │

```
