### 4.2 集成夹具与真实依赖

当前集成测试夹具使用共享 SQLite 内存数据库和 WebApplicationFactory，RabbitMQ 场景通过
`RUN_RABBITMQ_INTEGRATION_TESTS=true` 显式接入真实 broker；PostgreSQL 迁移和生产镜像启动由独立
runtime smoke 覆盖。这样既保持常规测试快速自包含，也避免把“SQLite schema 创建成功”误报为 PostgreSQL
迁移已验证。

```csharp
// 使用 WebApplicationFactory<Program> + 共享 SQLite；真实 RabbitMQ 场景单独显式启用
public class WorkOrderControllerTests : IClassFixture<IntegrationTestFixture>
{
    [Fact]
    public async Task FullLifecycle_ShouldSucceed()
    {
        // Create
        var createResponse = await _client.PostAsJsonAsync("/api/v1/work-orders", createReq);
        createResponse.StatusCode.Should().Be(HttpStatusCode.Created);
        var wo = await createResponse.Content.ReadFromJsonAsync<WorkOrderDto>();

        // Assign → Start → Complete → Accept → Close
        await _client.PutAsync($"/api/v1/work-orders/{wo!.Id}/assign", assignReq);
        await _client.PutAsync($"/api/v1/work-orders/{wo.Id}/start", null);
        // ... 完整链路验证
    }
}
```

## 六、E2E 测试详情

### 6.1 Playwright 项目依赖链

```
setup (健康检查+种子数据)
  └── auth (登录/注册) ──→ crud (设备/告警/工单 CRUD)
                            ├── realtime (SignalR/MQTT)
                            ├── advanced (导出/导入/MFA/OEE)
                            ├── auth-extended (Token/RBAC)
                            ├── errors (400/401/403/500)
                            └── edge-cases (SQLi/XSS/并发/离线)
```

### 6.2 安全测试覆盖

| 攻击类型 | E2E 场景 | 期望结果 |
|---------|---------|---------|
| SQL 注入 | POST body 含 "OR 1=1" | 400 + "请求被安全策略拦截" |
| XSS 注入 | POST body 含 "<script>" | 400 + "请求包含不允许的内容" |
| 路径遍历 | URL 含 "../" | 403 + "请求被安全策略拦截" |
| 超长输入 | 100KB payload | 400 (ASP.NET 自动截断) |
| 损坏 Token | 随机字符串 | 401 |
| 速率限制 | 高频请求 (60+/min) | 429 |
| 离线队列 | 断网→操作→恢复→同步 | 操作同步成功 |

### 6.3 实时推送覆盖

| 事件 | E2E 验证方式 |
|------|-------------|
| OnAlertTriggered | 用 MQTT 模拟器发异常遥测 → 检查前端告警列表实时更新 |
| OnWorkOrderCreated | API 创建工单 → 检查 SignalR 推送 |
| OnDeviceStatusChanged | 等待设备超时 → 检查设备列表状态更新 |
| OnGatewayOffline | 停止网关心跳 → 检查网关列表状态 |

### 6.4 关键配置

```typescript
// playwright.config.ts
{
  retries: process.env.CI ? 1 : 0,   // CI 失败重试 1 次防 flaky
  timeout: 60000,                      // 单用例超时 60s
  expect: { timeout: 15000 },         // 断言超时 15s (CI 环境较慢)
  workers: 2,                          // CI 中 2 个 worker
  fullyParallel: false,                // 跨租户隔离不能并行
}
```
