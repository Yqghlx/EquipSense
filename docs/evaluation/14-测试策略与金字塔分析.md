### 4.2 集成夹具与真实依赖

当前集成测试夹具使用共享 SQLite 内存数据库和 WebApplicationFactory，RabbitMQ 场景通过
`RUN_RABBITMQ_INTEGRATION_TESTS=true` 显式接入真实 broker，并固定到专用 `/equipai_test` vhost；
management API 断连同时校验连接名和 vhost。PostgreSQL 迁移和生产镜像启动由独立 runtime smoke 覆盖。

broker 上的测试清理误触碰其他拓扑。
