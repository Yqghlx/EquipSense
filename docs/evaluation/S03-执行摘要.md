# EquipSense 执行摘要 (Executive Summary)

> 面向管理层/利益相关者的 10 秒速览 · 2026-06-24 · v1.2.0

---

## 项目定位

**工业设备智能监控与预测维护 SaaS 平台**。核心承诺：故障前预警、告警后秒级根因分析、确认后自动工单闭环。

## 项目规模

```
~11 万行代码（源码+测试） · 492 次提交 · 2 个月 · 1 位开发者 · 11 个 Docker 服务
后端 376 文件 · 前端 192 文件 · 边缘网关 25 文件 · 测试 138+41 文件
135+ API 端点 · 30 个 Controller · 1,770+ 自动化测试 · 512 E2E 用例
```

## 技术栈

| 后端 | 前端 | 数据库 | 通信 | AI | 运维 |
|------|------|--------|------|-----|------|
| .NET 8 | React 19 | PostgreSQL 16 + TimescaleDB | MQTT + SignalR | 通义千问 (DashScope) | Docker Compose |
| EF Core 8 | TypeScript 6 | Redis 7 | WebSocket | ML.NET SrCnn | GitHub Actions |
| 模块化单体 | TanStack Query + Zustand | SQLite (边缘) | OPC UA + Modbus | Semantic Kernel | Prometheus + Grafana |

## 主要风险 (P0)

| 风险 | 影响 | 解决方向 |
|------|------|---------|
| 备份未完成恢复演练 | 灾备能力无法证明 | 异地同步 + 定期恢复演练 |
| MFA 恢复码尚未现场演练 | 恢复码保存不当或未验证可用性会延长高权限账户恢复时间 | 验证一次性恢复码、重新生成、审计和失效流程 |
| 读副本/容量未真实压测 | 大租户可能影响小租户 | k6 写路径与慢查询基线 |
| 单点开发者 | 故障响应依赖个人 | 知识转移与备选维护者 |
